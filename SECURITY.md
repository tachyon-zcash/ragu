# Security Policy

## Reporting Security Vulnerabilities

If you've discovered a security vulnerability in Ragu, please report it to us privately. You can do this by sending an email to [security@tachyon.z.cash](mailto:security@tachyon.z.cash) with the details of the vulnerability.

## Vulnerability Disclosure Policy

We appreciate your help in keeping Ragu secure. When you report a security vulnerability to us, we will:

1. Acknowledge your report and let you know that we're working on it.
2. Investigate the issue and determine its severity.
3. Fix the issue and release a new version of Ragu.
4. Publicly disclose the vulnerability and give credit to the reporter (if desired).

## Bug Bounty Program

We do not currently have a formal bug bounty program, but we appreciate responsible disclosure and may provide rewards for significant vulnerabilities on a case-by-case basis.
